# AI usage

File to PDF was built with [Claude Code](https://claude.com/claude-code),
Anthropic's coding assistant. Claude wrote most of the code, tests,
documentation, packaging and commit messages, working from requirements set
by the maintainer. The maintainer reviewed every change, tested conversions on
real files, and decided what was merged, and remains responsible for the
project.

This statement covers the whole project, from its first commit on.

## Contributions made with AI tools

AI-assisted contributions are welcome on the same terms as any other. If you
used an AI tool for a pull request, say which one and what it did in the pull
request description (for example "tests written with an assistant, reviewed
and run locally"). You are responsible for the change: understand it, run the
tests, and check the PDFs it produces.
