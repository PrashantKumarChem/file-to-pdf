# Security

## Supported versions

Fixes go into the latest release only.

## Reporting a vulnerability

Please don't report security problems in a public issue. Use
[Report a vulnerability](https://github.com/PrashantKumarChem/file-to-pdf/security/advisories/new)
on the repository's Security tab, which opens a private advisory visible only
to you and the maintainer.

Include the version, what an attacker could do, and the steps or a file that
shows it. This is a one-person project, so replies are best effort, but every
report will be answered.

Examples of what to report privately:

- a PDF that reveals something it shouldn't, such as local folder paths;
- the app reading or writing files other than the ones you chose and its
  output and log folders;
- a file whose conversion runs code on your computer outside the browser that
  prints it.
